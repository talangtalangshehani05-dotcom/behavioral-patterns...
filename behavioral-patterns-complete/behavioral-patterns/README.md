# Behavioral Design Patterns in PHP
**Laboratory Activity #4 — Plain PHP implementation**

This project demonstrates all 11 Behavioral Design Patterns listed in the activity PDF. Each numbered folder contains:
- `index.php` — runnable demonstration
- `classes.php` — interfaces and classes used by the demonstration

## Requirements
- PHP 8.0 or later recommended
- No framework or Composer packages required

## Run a pattern
Open a terminal in the project directory and run, for example:

```bash
php 01-chain-of-responsibility/index.php
php 02-command/index.php
```

Repeat for folders `01` through `11`. Alternatively, run the project through a local PHP installation such as XAMPP by placing the `behavioral-patterns` folder inside `htdocs`, then visit the relevant folder in your browser.

## Patterns included
1. Chain of Responsibility — Student Request Processing System
2. Command — Student Action/Command System, including undo
3. Interpreter — Student Search/Query System
4. Iterator — Student Record Collection
5. Mediator — Student Communication System
6. Memento — Student Profile Undo System
7. Observer — Grade Notification System
8. State — Student Enrollment Status
9. Strategy — Grade Calculation System
10. Template Method — Student Report Generation
11. Visitor — Student Record Operations
